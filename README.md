# Fission MSL

[![GPLv3 License](https://img.shields.io/badge/License-GPL%20v3-yellow.svg)](https://choosealicense.com/licenses/gpl-3.0/)
[![.NET Version](https://img.shields.io/badge/.NET-8.0-%235d2b90
)](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)


Fission MSL is an application for hosting and managing game servers on your local system.
Currently Fission MSL can only host Minecraft servers, but it is planned to have support for other games in the future.

Fission MSL is currently in development and has no release builds yet, feel free to compile the source though.


## FAQ

#### Where can I download Fission MSL?

Here, eventually. Once I have all of the features I want for the v1.0 release, I will put it available to download from this page. For now you have to compile the source.

#### Why make Fission MSL?

I am making Fission MSL because I feel like it should be easier for people to create and manage their own game servers, and I am tired of being the magical wizard of the group that can make game servers.

#### How do I use Fission MSL?

I will eventually have documentation built into the application, but otherwise I feel like it should be pretty simple to figure it out. One of the goals of this application is to make it very accessible for anyone to host a game server, and part of that includes ease of use.
